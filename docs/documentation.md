## Hardware and first setup

Read the [official manuals](https://drive.google.com/drive/folders/1yOtrqV2SbzW65fz0QdeuqpO0F1IuW298) for power requirements, connector assignments and installation instructions. Match the schematic and manual revision to your board.

## Firmware and development

Use [Downloads](downloads.md) to obtain compatible images, tools, SDKs and reference documents. Follow the selected SDK's build instructions and component licenses.
